HUKM AI Windows Controller - Consolidated Install/Update (v1.9.2)

PREFERRED FUTURE ONE-TIME INSTALLER:
- HUKM-Setup-v1.9.2.exe is now built as a SEPARATE test artifact.
- It is ONE Windows EXE: no manual extraction of the inner legacy ZIP is necessary.
- It does not enable automatic startup, send messages or delete pairing settings.
- WARNING: test build is UNSIGNED, not yet published as a trusted direct website download.
- Future website-managed auto-updates require a signed update channel, integrity checks,
  clear owner approval, rollback and real laptop acceptance. Not yet enabled.
- The legacy ZIP process below remains for existing installations and CI compatibility.

0. The GitHub Actions artifact contains TWO files: HUKM-Windows-Controller-v1.9.2.zip and its .sha256 checksum.
   On PowerShell run Get-FileHash .\HUKM-Windows-Controller-v1.9.2.zip -Algorithm SHA256
   and compare to the .sha256 file before extracting the inner ZIP.
1. Extract the ENTIRE inner ZIP to one temporary folder.
2. Close any previous HUKM Controller black window. Do not delete old folders yet.
3. Run INSTALL_OR_UPDATE.cmd. It installs to LOCALAPPDATA/HUKM AI/Controller, safely backs up any previous EXE.
4. Run VERIFY_HUKM.cmd and check the installed version and existing pairing.
5. Run START_HUKM.cmd only when ready for live tests. Confirm ONLINE in the authenticated relay dashboard.
6. Verify the actual backend first (not GitHub Pages): https://hukm-ai-relay.onrender.com/api/health must return valid JSON showing v1.9.2.
   This public HTTP check is NOT proof of pairing or a working Windows application; real laptop tests are deferred by the owner.
7. Only when satisfied, run ENABLE_AUTOSTART.cmd once; thereafter sign-in to Windows starts Controller.

Important: User settings/device token remain in APPDATA/HUKM AI. This ZIP does not contain or replace the database, keys, Chrome profiles or WhatsApp data.

Do NOT delete old HUKM folders, especially any /data or .env, until your accounts, prior data, local and remote website and autostart are separately verified and backed up.

CURRENT CAPABILITIES:
- Owner-approved multi-step HUKM task planning from natural language (bounded validated actions).
- Notepad typing, Chrome profile launch to configured ChatGPT/Calendar sites, Projects, notes and saved instructions.
- Existing device pairing, safe app/browser actions and WhatsApp best-effort unread checking.

NOT YET COMPLETE:
- This adds approved foreground UIA inspection, Personal WhatsApp visible read/draft/attachment preview, Calendar event drafts, ChatGPT prompt/submission/visible download actions.
- Automatic real WhatsApp sending, Calendar OAuth event creation/attendee invitations, fully autonomous visual agent and real-PC regression testing remain incomplete.
- Website accessibility controls can change; user must run real laptop acceptance tests.
- "Success" for an input event means sent, not independently verified.

Protect your account credentials. Never type passwords or OTP codes in HUKM prompts.
